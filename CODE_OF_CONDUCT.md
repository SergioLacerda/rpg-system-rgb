# Code of Conduct

## Our Standard

Project spaces should stay respectful, technical, and useful. Contributors are
expected to:

- discuss ideas and code without personal attacks;
- assume good faith while still asking for evidence;
- keep issues and pull requests focused on the project;
- respect maintainer decisions about scope and timing.

Unacceptable behavior includes harassment, discriminatory language, threats,
spam, or sustained disruption of project work.

## Enforcement

Maintainers may edit or remove comments, close issues, block users, or decline
contributions that violate this code of conduct. Enforcement is best-effort and
scaled to the project's maintainer capacity.
