# Licensing

The repository currently uses the license in [LICENSE](LICENSE): Creative
Commons Attribution 4.0 International (CC BY 4.0).

That license applies to the repository as published today, including rules,
documentation, examples, scripts, and source code.

## Split-License Decision

A split license model is not adopted yet.

If the project later needs clearer separation between software and creative
rules text, use a dedicated decision record before changing license headers or
release packaging. A likely future model would be:

| Surface | Candidate license |
| --- | --- |
| Code, scripts, CI, and tooling | MIT or Apache-2.0 |
| Rules text, examples, docs, and art | CC BY 4.0 |

Until that decision is made, contributors should assume the current repository
license applies to their contributions.
