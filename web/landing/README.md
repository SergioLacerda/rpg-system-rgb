# RGB System Web

Astro/Node landing page for RGB System, with pt-BR/en UI copy, a MkDocs-backed Library surface, and Skills presentation routes. The current page is based on the approved scaffold in `.analysis/pending/astro-project`.

## Run

```bash
npm install
npm run dev
```

## Library

The Library tab is generated from the repository `docs/` tree with MkDocs.
The generated static site is written to `web/landing/public/library/` and is
copied into Astro's `dist/` during `npm run build` when the root Makefile is used.

From the repository root:

```bash
make docs-install
make docs-build
make docs-preview
make landing-build
```

`make landing-build` depends on `docs-build`, so production landing artifacts include
the compiled Library at `/library/` under the configured Astro base path.

## Structure

- `src/i18n/dictionary.ts` stores all UI strings for pt-br/en.
- `src/content/library/{pt-br,en}/<section>/<slug>.md` is transitional scaffold content. The public Library source is `docs/` and the compiled route is generated by MkDocs.
- `src/pages/[lang]/...` defines localized routes for `/pt-br/*` and `/en/*`.
- `src/pages/index.astro` redirects `/` to `/pt-br/`.
- `src/components/` contains Header, Footer, Logo, VectorCard, CodeBlock, and SkillCard.
- `src/styles/tokens.css` defines palette and font CSS variables.
