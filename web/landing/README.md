# RGB System Web

Astro/Node landing page for RGB System, with pt-BR/en UI copy, a Go-generated
Library surface, stable PDF download links, and Skills presentation routes.

## Status

| Surface | Status | Notes |
| --- | --- | --- |
| Root route | Implemented | `/` resolves to the Portuguese landing experience; `/pt-br/` and `/en/` are localized. |
| Library | Implemented | The root Makefile builds Go publication output into `public/library/` before Astro packaging. |
| PDF links | Implemented | Home CTAs point to `/downloads/rgb-system-core-v2-latest-{locale}.pdf`. |
| Skills pages | Implemented as presentation | Specialist/Maker pages describe ecosystem roles; skill execution stays outside the landing app. |
| Maker and Specialist products | Contract defined | The landing may describe their contracts, but it must not present them as available runtime products. |

## Run

```bash
npm install
npm run dev
```

## Library

The Library tab is generated from the repository `docs/` tree with `cmd/rgb docs library`.
The generated static site is written to `web/landing/public/library/` and is
copied into Astro's `dist/` during `npm run build` when the root Makefile is used.

From the repository root:

```bash
make docs-build
make docs-preview
make landing-build
```

`make landing-build` depends on `docs-build`, so production landing artifacts include
the compiled Library at `/library/` under the configured Astro base path.

## Structure

- `src/i18n/dictionary.ts` stores all UI strings for pt-br/en.
- `src/content/library/{pt-br,en}/<section>/<slug>.md` is transitional scaffold content. The public Library source is `docs/` and the compiled route is generated by `cmd/rgb docs library`.
- `src/pages/[lang]/...` defines localized routes for `/pt-br/*` and `/en/*`.
- `src/pages/index.astro` redirects `/` to `/pt-br/`.
- `src/components/` contains Header, Footer, Logo, VectorCard, CodeBlock, and SkillCard.
- `src/styles/tokens.css` defines palette and font CSS variables.

## Known Follow-Ups

- Skills pages are static presentation surfaces; install/execution logic stays outside this scaffold, and contract-defined skills must not be marked as available runtime products.
- `site` and `base` in `astro.config.mjs` assume GitHub Pages under the `rpg-system-rgb` repository.
